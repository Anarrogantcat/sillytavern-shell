## v0.8.53 (2026-10-14) — 支持「标签独占一行」（真机：插件"完全没生效" ✗）

用户截图：标签**全裸露**（`染·台词` 一行、内容在下一行）⇒ 说"插件完全没生效"。

**真因不是没加载** ✗，而是模型换了写法：
```
染·台词                ← 标签独占一行
"就是这样的，全都交给我来收割。"   ← 内容在下一行
沙良·心理
（她感觉自己像一块面团。）
```
⇒ 我们的解析要求 `名字·层 内容` **在同一行** ⇒ 一个都认不出 ⇒ 标签全裸露 ✗

**修法**：新增 `mergeSplitTags()` —— 在切段之前先把这种写法合并成一行 ✓
· 某行**恰好**是 `名字·层`（层是五个之一、行尾没有内容）⇒ 与**下面第一个非空行**合并 ✓
· 只合并紧邻的一行；该行本身（以及中间的空行）从结果里去掉 ✓
· 正常的一行写法**完全不受影响** ✓（夹具断言）
· 标签后面没有内容、也没下一行 ⇒ 原样不动 ✓

夹具 642 → 648。说明：只改扩展 + 脚本 → 不升套壳版本号、不打 tag、不发包（AGENTS 1.1）
