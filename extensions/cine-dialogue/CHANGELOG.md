## v1.0.4 (2026-10-14) — **推翻我自己当年的决定**：状态栏键名不能再被吃

```

`行动: "…"` 这类「层名 + 中文冒号 + 正文」的行，按动作行（无名字）渲染：
```

⇒ **就是这条决定在毁状态栏** ✗：`行动:` / `内心:` **正是状态栏 YAML 的键**，

**本版反转**：`:` 分隔时**只认五个正名**（动作/感官/台词/心理/旁白）✓
