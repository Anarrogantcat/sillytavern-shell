## v0.7.0 (2026-10-13) — 面板「生成专属预设」：别人也能自助适配

### 背景：一条版权红线决定了做法
原预设许可写着「可以二改，**禁止二传**，拿功能要先问我，署名」
⇒ **我们不能把专属预设打包分发**（上传、塞进安装包、放进仓库都不行）。

所以唯一合规的路子是 **分发「配方」+ 各自在本地生成**：
- 仓库里只有配方代码，**没有预设内容**
- 派生动作发生在**使用者自己的机器上**，用**他自己那份原预设**

### 做了什么
1. **配方抽成纯函数** `applyPresetRecipe()`（在 `logic.js`）
   - **纯**：内部深拷贝，**绝不改传入对象**
   - **幂等**：重复套用只报告「已是」，不叠加条目
   - **容错**：传非对象/空对象 → `ok:false` 或原样返回，**不抛异常**
   - 与 `PRESET_UPSTREAM` / `PRESET_RECIPE` / `presetNoteText()` 一起导出
2. **面板新增「专属预设」一块**（在「格式错误」区之前）
   - 文件选择框 + 「只看会改什么」+「生成专属预设」
   - 选你手上那份原预设 → 浏览器内套配方 → **下载** `××× + 分镜.json` → 到 ST 预设面板导入
   - **全程本地**：不发任何网络请求；预设内容不经过任何服务器
   - 面板上直接写着原作者与许可（署名可见）
3. **CLI 改成调同一份配方**（`scripts/cine-preset.mjs` 只负责读文件 / 写文件 / 报告）
   - 新增守卫：**CLI 里不许再出现 `maxDepth = 数字`** —— 谁把配方抄回去，夹具立刻报错
   - CLI 现在**以磁盘上现有派生文件为基础**再套配方 → 你自己在派生文件里做的额外调整不会被抹掉
4. 顺带：`0.6.3` 那两条「配方内容」合规断言**改成查 `logic.js`** —— 它们正是被这次搬迁抓出来的

## v0.6.2 (2026-10-13) — 英文层名自动纠正成中文（真机：`染·action …`）

### 现象与定性
真机：模型把层名写成了**英文** —— `染·action 我低头凑近她的耳畔，温热的呼吸扑在她的颈皮上。`
**是生成的问题**（模型自己漂移），但它**暴露了我们一个真 bug**：
认不出的层名 → 整行掉进 `text` 直通 → **`染·action` 原样显示在界面上** ✗
这违反本项目铁律「标签绝不出现在 UI」。

### 修法：层名别名表，归一到中文
- 新增 **`LAYER_ALIAS`**：规范中文层名 ← 各种写法
  - 动作 ← `act` `action` `move` `motion`…
  - 台词 ← `speech` `dialogue` `say` `talk` `line` `voice`…（中文变体「对白」「说话」）
  - 感官 ← `sense` `sensory` `feeling` `body` `touch`…（「感受」「感觉」）
  - 心理 ← `mind` `thought` `inner` `monologue` `psych`…（「内心」「想法」「心声」）
  - 旁白 ← `narration` `narrator` `desc` `scene`…（「叙述」「旁述」）
- `parseLine` 用 `canonLayer()` 归一 → **`染·action` 现在正确按「动作」渲染**（层名照旧不显示）✓
- 顺手修掉一个潜伏问题：`rowRegexFor` 原来在「没有自定义层」时**直接返回只认 5 个中文层名的 `RE_ROW` 常量**，
  别名根本进不去 → 现在统一走可缓存的正则构建（key 里带 `lenient` 标志，避免两种模式互相覆盖缓存）
- **不留白**：`repaired: 'alias'` → hover 说明「层名是非规范写法，插件已自动归一到对应中文层」

### `lenientLayers`（**默认关**）—— 一个我差点做错的取舍
一开始我把「认不出的层词也当自定义层」设成**默认开**（想彻底杜绝标签露出）。
**夹具当场抓出问题**：`·` 也出现在外文名里 —— `阿尔托莉雅·潘德拉贡 说道`
会被误判成「名字=阿尔托莉雅 / 层=潘德拉贡」的**合法行**，**静默改写别人的正文** ✗✗ 比偶尔露出标签更糟。
⇒ **默认关**；英文层名由别名表覆盖，**不靠乱认**。想更激进可在面板打开。

## v0.6.1 (2026-10-13) — 修两个真机问题：未标注行没对齐 + 模型漏写「名字·」

### ① 未标注行没对齐到正文列（真机：「旁白没有和上面/后面的内容对齐」）
- **原因**：未标注行留在网格**外面**（这样 markdown 才有效），于是从 x=0 开始；
  而正文列在网格第 2 格，带 3px 边框 + .7em 内边距 → 差一截
- **修法：空锚点 + 渲染后测量**（新增 `alignPlains()`）
  - `renderMessageHTML` 在每段未标注内容前埋 `<span class="cd-anchor" aria-hidden="true">`
  - `decorate()` 量出「名字列宽 + 正文格边框与内边距」，只给**锚点之后、下一个锚点/网格之前**的兄弟节点加左内边距
  - **不包内容**（markdown 不受影响）· **不猜节点归属**（卡自己的前端块不在锚点区间里，不会被碰）
  - 裸文本节点会被包成 `display:block` 的 span（发生在渲染**之后**，不影响 markdown）

### ② 模型漏写「名字·」→ 层名当正文露出来（真机：`心理 我真的……`）
- 新增 **`repairLines()`**，三档，**默认 `safe`**：

| 档 | 修什么 | 依据 |
|---|---|---|
| `off` | 不修 | — |
| **`safe`**（默认） | ① 只写了层名 → 补「同楼最近标注过的角色」② 纯 `「…」` 行 → 台词 | 层名是模型自己写对的；引号 = 说话 |
| `aggressive` | 再把**完全没标注**的行归为旁白 | **不猜角色**（宁可当旁白，也不假装是某个角色说的） |

- **不猜方向**：找不到可参照的角色时**不修**；**不改人称**（那是内容，不是格式）
- **必须可见**：补过的行加 `cd-fix`（名字格下虚线）+ hover 说明「这一行的名字是插件补的」
- 面板可随时切换档位；**补全只发生在原本就显示为裸文本的行上**，不会动已经正确的行

### ① 间距太大
- **原因**：模型**每行之间都空一行** → `parseBlocks` 把每一行切成**独立分组** →
  组间同时叠加 **`.cd-sep` 分隔线（.45em 上下外边距）** 与 **行间距 `rowGap`** ⇒ 双重撑开
- **修法**：

  - 新增 `showSeparators`（默认 **false**）→ 默认**不画**分隔线，面板里可开

  - 三者全部进面板

### ② 点击选项没反应（真 bug）
- **原因**：`wireOptions()`（逐个绑点击）**只在 DOM 降级路径里被调用**；
  而实际跑的是**钩子路径** —— HTML 是 **ST** 插进 DOM 的（`addOneMessage` / 流式重写 / `updateMessageBlock`），
  我们**没有"插完之后"的时机去绑事件** ⇒ 按钮全是死的

## v0.2.1 (2026-10-13) — 自检修出 3 个缺陷

### 修 ①（严重）：钩子路径会把**正文整段丢掉**
`renderMessageHTML` 原来用**整条原文**做 `hasOurLines` 判据：

```js
if (!hasOurLines(text)) return null;   // ← 用了整条原文
```

若标签**只出现在 `<htmlcontent>` / `[FRONTEND]` 里**，整条原文判为「有我们的行」，
但 `splitSections` 把外壳切走后正文里没有我们的行 → `renderMessage` 返回 `html:null`
→ 继续拼 `'' + 前端 + 选项` 得到**非空字符串** → 钩子的 `!res.html` 拦不住 → **正文消失**。

**改法**：判据改用**切完之后的正文**，并加双保险 `if (!res.html) return null`。

### 修 ②：钩子路径丢失「首行缩进」与「名字列统一」
`run()` 里写了 `if (hookActive()) return;` —— 一退到底，于是 `applyIndent` / `unifyNameColumn`
在钩子路径下**永远不跑**；`refreshAt()` 同样直接 return。

**改法**：抽出 `decorate(mesEl)`（只做这两件「必须看渲染结果才能做」的事），
**两条路径都跑**：钩子路径 → 只补装饰；降级路径 → 渲染 + 装饰。

### 修 ③：夹具把版本号写死 → 每次升版本假红
`scripts/compat-logic-test.mjs` 夹具 78 断言 `const VERSION = '0.33.0'` 字面量，
升到 0.33.1 就失败（本轮实测：658/0 → 657/1）。

**改法**：改成断言「代码里的 `VERSION` == `manifest.json` 的 `version`」且 ≥ 0.33.0 ——
意图不变（版本号真升了、且只有一处来源），但不再随版本漂移，**还能抓到真正的漂移**。

### 夹具
- **73 → 76 条**：新增 3 条**回归对照**（按 AGENTS §1.4.6「旧行为可复现 + 新行为断言同时存在」）
  - 旧行为可复现：`hasOurLines(整条原文) === true`（证明这个坑真实存在）
  - 新行为锁死：`renderMessageHTML(...) === null`（绝不吃掉正文）
  - 正文判据确认为 false

## v0.2.0 (2026-10-13) — 接入核内渲染漏斗钩子：标签永不进 DOM
