# 剧情推进器 Plot Pilot

发送栏上方的两个按钮：**▶ 续写** / **⏭ 推进节点**。它代替了原来那份酒馆助手脚本「继续按钮」，
区别是：**配置进 ST 设置（可备份）、逻辑与界面分离（可在 Node 里跑测试）、带公开 API（便于继续扩展）**。

## 为什么从酒馆助手脚本改成 ST 扩展

| 维度 | 旧：酒馆助手脚本 | 新：ST 扩展 Plot Pilot |
|---|---|---|
| 配置存放 | `localStorage`（换端口/清缓存就丢，不进 ST 备份） | `extension_settings["plot-pilot"]`（随 ST 设置持久化、可备份可迁移） |
| 版本与心跳 | 无 | 写入 `loadedAt / loadedVersion / runCount / lastAction`，排查时能确认"装没装、跑没跑" |
| 可测试性 | 逻辑和 DOM 混在一起，只能手点 | `logic.js` 是纯函数，`node scripts/plot-pilot-test.mjs` 直接跑断言 |
| 发送通道 | 只能模拟点击 | `api`（调用 ST 内部 `Generate`）/ `dom`（模拟点击）/ `auto` 自动退回 |
| 每卡差异 | 只有全局一份配置 | 全局 + 每卡覆盖（显示/隐藏、文案各自可改） |
| 扩展入口 | `window.YDContinue` | `window.PlotPilot`（含 `continue() / advance() / sendText() / recheck()`） |

## 安装 / 更新

```powershell
# 仓库根目录执行（会把 extensions/ 下所有扩展同步到 ST 数据目录）
node scripts/ext-install.mjs              # 全部
node scripts/ext-install.mjs plot-pilot   # 只同步本扩展
node scripts/ext-install.mjs --dry-run    # 只看差异不写入
```

同步后刷新 ST 页面（或在 扩展 面板里重载）。

## 面板设置

| 设置项 | 默认 | 说明 |
|---|---|---|
| 启用 | 开 | 总开关 |
| 在发送栏上方显示按钮 | 开 | 关闭后按钮条整条移除（面板里仍可改配置） |
| 「续写」按钮文字 / 发送内容 | `▶ 续写` / `（按照当前剧情继续推演）` | 发送内容就是点一下会发给模型的那句话 |
| 「推进节点」按钮文字 / 发送内容 | `⏭ 推进节点` / `请根据当前 {var}，推进至下一个 step` | `{var}` 会替换成探测到的变量名（如 `blueprint_controller`） |
| 兜底内容 | `（推进到下一个剧情节点）` | 卡里没有剧本系统时发送这句，不会发出模型看不懂的指令 |
| 弱信号也显示「推进节点」 | 开 | 卡里只出现「剧本」「蓝图」这类泛词时是否也显示（沿用旧脚本行为，关掉后这类卡只剩「续写」） |
| 发送通道 | 自动 | `api` 走 ST 内部 `Generate`；`dom` 模拟点击；自动优先 api、异常退回 dom |
| 防连点窗口 | 800ms | 窗口内重复点击直接忽略 |
| 忽略旧「继续按钮」脚本冲突 | 关 | 见下 |

### 本卡设置

「续写 / 推进节点」两个按钮可以按卡单独设为 跟随全局 / 显示 / 隐藏，文案也能按卡覆盖（留空 = 跟随全局）。
切换角色卡后点「重新探测当前卡」即可刷新面板显示。

### 旧脚本冲突（重要）

如果酒馆助手里那份「继续按钮」脚本还在启用，页面上会出现**两套按钮**。本扩展检测到 `window.YDContinue`
或旧的 `#yd-quick-continue-wrapper` 元素时会**自动进入待命状态**（不注入自己的按钮，只在面板里提示），
避免按钮打架。处理方式二选一：

1. 推荐：到 酒馆助手 → 脚本 里停用/删除旧的「继续按钮」脚本，然后刷新页面；
2. 暂时保留：勾选面板里的「忽略旧脚本冲突」，本扩展照常工作（两套按钮会同时存在）。

## 探测规则

- **强信号**：卡里出现 `blueprint_controller` / `blueprint_manager` / `blueprint` / `剧本控制器` / `剧情蓝图` 等 → 显示「推进节点」，并用真实变量名填 `{var}`；
- **弱信号**：只出现「推进至下一个 step」「剧情节点」「剧本」「蓝图」等泛词 → 默认也显示（措辞回落成「剧情蓝图」），可在面板关掉；
- **无信号**：只显示「续写」，此时「推进节点」只在被本卡设置强制显示时才出现，发送兜底文案。

探测范围：角色卡描述 / 性格 / 场景 / 开场白 / 示例对话 / 系统提示 + 世界书全部条目 + `extensions` 数据与酒馆助手脚本正文。

## 公开 API（继续扩展用）

```js
PlotPilot.cfg                       // 当前配置（只读快照）
PlotPilot.detection                 // 当前卡的探测结果 {has, confidence, varName, hits}
PlotPilot.detect()                  // 重新探测并返回结果
PlotPilot.recheck()                 // 重新探测 + 重画按钮条/面板
PlotPilot.continue()                // 等价于点「续写」
PlotPilot.advance()                 // 等价于点「推进节点」
PlotPilot.sendText("自定义内容")     // 直接走本扩展的发送通道（含防连点）
PlotPilot.setConfig({ sendMode: "dom" })  // 改配置（同时持久化并重画界面）
```

## 边界

- 生成进行中点击会被忽略并提示（不会排队，避免意外双发）；
- `api` 通道依赖 ST 的 `#send_textarea` 与 `Generate()`；两者都在时会清空输入框，行为与手动发送一致；
- 弱信号判断是启发式的，误判时用「本卡设置 → 显示/隐藏」逐卡纠正。
