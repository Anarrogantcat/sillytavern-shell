# 卡兼容助手 (card-compat) v0.2.8

保证**角色卡状态栏正常显示**且**数据正常更新**，不修改 ST 本体、不修改任何角色卡。

## 能力总览

| 分组 | 能力 |
|---|---|
| 守护 | 锚点（`<StatusPlaceHolderImpl/>`、`<StatusBar>`、`<status!>` 等）缺失按设置补、未闭合补闭合、重复占位符合并、畸形结束标签（`</Tag` 缺 `>`）补全 |
| 数据块 | `<UpdateVariable>` 等数据块**绝不改动内容**；未闭合补闭合；缺失只报警（绝不伪造数据） |
| 清理 | 本卡未声明、也没人渲染的结构块（模型回显世界书 `<world_setting>`、自创 `<status_block>`）成对删除；只有开标签的只报告 |
| YAML | 结构块引号错配（英文引号开头 + 中文引号结尾）修复、含「: 」「 #」的裸值自动加引号、**结构级修复**（列表项行内映射 + 更深兄弟键 / 引号后跟「, 文字」，0.3.0）、用自带 js-yaml 严格校验并报警 |
| 变量块兜底 | 模型漏输出变量块时，用「只输出补丁」短提示词静默补一次（校验通过才写盘），再经 MVU API 写回；连续失败 2 次暂停 10 分钟 |
| 变量路径白名单 | 从卡的 `变量更新规则` 抽路径，补丁越界只提示不改写；面板列出「声明命中 / 组内未声明 / 越界」 |
| 覆盖度 | 「本卡要求 vs 本轮实际」对照表 + 覆盖度趋势方块条（最近 10 轮对比前 10 轮） |
| MVU 联动 | 探测 `Mvu` API；只读试解析本轮变量块；检测 MVU「额外模型解析」开启时主动让位避免双写 |
| 渲染联动 | 修正正文后的重渲染会补发 `MESSAGE_UPDATED`，让酒馆助手（TavernHelper）立刻重画前端块（0.2.9 起）；历史楼层默认只改文本不重渲染，不拆已画好的状态栏 |
| 通知 | 连续 3 楼缺变量块 → 气泡提醒（10 分钟内不重复） |
| 界面 | 面板五组分区、中英双语（自动/中文/English）、消息区 zoom 缩放与字号下限 |

## 时机

挂在 `MESSAGE_RECEIVED`（早于渲染与卡正则），所以卡片自己的脚本随后能命中修正后的文本；
流式生成由 `GENERATION_ENDED` 兜底，渲染后由 `CHARACTER_MESSAGE_RENDERED` 校验是否还被卡脚本接管。

## 安装

把本目录复制到 `<SillyTavern数据目录>/default-user/extensions/card-compat/`，然后刷新 ST 页面。
（本仓库提供 `node scripts/ext-install.mjs card-compat` 一键同步；套壳启动时也会自动部署）

## 对外钩子

其它扩展或酒馆助手脚本可以调用 `window.CardCompat`：

`version / profile() / guard(id) / coverage(id) / validatePaths(block) / applyToMvu(block,id) / writeBack(id) / mvu() / invalidate() / stats() / trend()`

## 边界

- 卡自带「隐藏状态栏」类脚本时，对应标签进入白名单，**不会被补**（补了反而多出面板）。
- 只补标签、不动正文与数据；所有动作在面板可见；一键关闭即完全还原。
- 变量兜底默认**关**（会调用 API），需要时在面板第②组打开。
