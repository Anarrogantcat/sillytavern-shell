# 卡兼容助手 (card-compat)

保证**角色卡状态栏正常显示**且**数据正常更新**，不修改 ST 本体、不修改任何角色卡。

## 三层能力

| 层 | 作用 |
|---|---|
| 锚点守护 | 卡的状态栏锚点（`<StatusPlaceHolderImpl/>`、`<StatusBar>`、`<status!>` 等）缺失时按设置补；未闭合时自动补结束标签 |
| 数据块守护 | `<UpdateVariable>` 等数据块**绝不改动内容**；未闭合补闭合；缺失只报警（绝不伪造数据） |
| 字号 | 消息区 `zoom` 缩放（能放大卡内写死的 px）+ 字号下限 `max(Npx, 1em)` |

## 时机

挂在 `MESSAGE_RECEIVED`（早于渲染与卡正则），所以卡片自己的脚本随后能命中修正后的文本。

## 安装

把本目录复制到 `<SillyTavern数据目录>/default-user/extensions/card-compat/`，然后刷新 ST 页面。
（本仓库提供 `node scripts/compat-install.mjs` 一键同步）

## 边界

- 卡自带"隐藏状态栏"类脚本时，对应标签进入白名单，**不会被补**（补了反而多出面板）。
- 只补标签、不动正文与数据；所有动作在面板可见；一键关闭即完全还原。
