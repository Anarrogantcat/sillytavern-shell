# 卡兼容助手 (card-compat) v0.13.2

保证**角色卡状态栏正常显示**且**数据正常更新**，不修改 ST 本体、不修改任何角色卡。

## 能力总览

| 分组 | 能力 |
|---|---|
| 守护 | 锚点（`<StatusPlaceHolderImpl/>`、`<StatusBar>`、`<status!>` 等）缺失按设置补、未闭合补闭合、重复占位符合并、畸形结束标签（`</Tag` 缺 `>`）补全 |
| 数据块 | `<UpdateVariable>` 等数据块**绝不改动内容**；未闭合补闭合；缺失只报警（绝不伪造数据） |
| 清理 | 本卡未声明、也没人渲染的结构块（模型回显世界书 `<world_setting>`、自创 `<status_block>`）成对删除；只有开标签的只报告 |
| YAML | 结构块引号错配（英文引号开头 + 中文引号结尾）修复、含「: 」「 #」的裸值自动加引号、**结构级修复**（列表项行内映射 + 更深兄弟键 / 引号后跟「, 文字」，0.3.0）、用自带 js-yaml 严格校验并报警 |
| 补丁核对 | **补丁生效自检**（0.9.4）：对比该楼与上一楼 `stat_data`，直接判「MVU 到底应用了没」；**状态级核对**（0.11.0）第三列区分「值真的变了 ✅ / 写了但没变 ⚠️ / 写的本来就一样 ➖ / 本轮没写 ○」；**切卡重建**（0.13.2）：换角色卡/换聊天立即按当前卡重报表，不再沿用上一张卡的表 |
| 变量兜底 | **A 自动**（0.10.0）：检测不到 MVU 时自己从卡的 `[InitVar]` 建初值、逐楼应用 `<JSONPatch>` / `_.set(...)` 并写回；**B 手动**：输入框上方「补应用变量」按钮。0.11.0 起**只修没生效的楼层**（以 MVU 真实值为基线、`delta` 只加一次、幂等可重复跑）；模型漏输出变量块时用「只输出补丁」短提示词静默补一次（校验通过才写盘）；连续失败 2 次暂停 10 分钟 |
| Zod 结构 | 静态解析卡的 MVU schema（helper 引用 / 别名内联 / `z.record` / `z.array` / `enum` `union` `literal` / `prefault` `default` `??` / `.min` `.max` `.int()` / `.catch()` / transform 白名单，0.13.0）：夹取（`_.clamp`）、范围、类型（含 `z.coerce` 与 `z.string()` 之分）、枚举、整数/取整、default 兜底；写入时按结构**强制校验**，不合规就跳过并记账，不写脏值 |
| 收支保护 | 某楼补丁会把「初值非负」的数值扣成负数 → 判该楼算术与真实余额不自洽，**整楼 `delta` 不应用**（只应用 `replace`）并提示；已写坏的楼层可自愈修回（0.12.0） |
| 变量路径白名单 | 从卡的 `变量更新规则` 抽路径，补丁越界只提示不改写；面板列出「声明命中 / 组内未声明 / 越界」 |
| 覆盖度 | 「本卡要求 vs 本轮实际」对照表 + 覆盖度趋势方块条（最近 10 轮对比前 10 轮） |
| MVU 联动 | 探测 `Mvu` API；只读试解析本轮变量块；检测 MVU「额外模型解析」开启时主动让位避免双写；MVU 在运行时它的自动兜底**完全不接管**，避免同一轮被解析两次 |
| 渲染联动 | 修正正文后的重渲染会补发 `MESSAGE_UPDATED`，让酒馆助手（TavernHelper）立刻重画前端块（0.2.9 起）；历史楼层默认只改文本不重渲染，不拆已画好的状态栏 |
| 通知 | 连续 3 楼缺变量块 → 气泡提醒（10 分钟内不重复） |
| 界面 | 面板分区（守护/清理/校验/兜底/日志 + 体检）、中英双语（自动/中文/English）、面板字号、消息区 zoom 缩放与字号下限；扩展信息卡 + 「查看日志」弹窗 |

## 时机

挂在 `MESSAGE_RECEIVED`（早于渲染与卡正则），所以卡片自己的脚本随后能命中修正后的文本；
流式生成由 `GENERATION_ENDED` 兜底，渲染后由 `CHARACTER_MESSAGE_RENDERED` 校验是否还被卡脚本接管。
0.11.0 起：检测到某楼补丁没生效时，按 MVU 的真实值做**幂等重算**（只补没生效的楼层，已生效的一律不动，`delta` 只加一次；修完再跑 0 写入）。
0.13.2 起：`CHAT_CHANGED` / `MESSAGE_RECEIVED` / `CHARACTER_MESSAGE_RENDERED` + 3 秒看门狗共同盯着「角色 id + 头像」，换卡即重建面板。

## 安装

把本目录复制到 `<SillyTavern数据目录>/default-user/extensions/card-compat/`，然后刷新 ST 页面。
（本仓库提供 `node scripts/ext-install.mjs card-compat` 一键同步；套壳启动时也会自动部署）

## 对外钩子

其它扩展或酒馆助手脚本可以调用 `window.CardCompat`：

`version / profile() / guard(id) / coverage(id) / validatePaths(block) / applyToMvu(block,id) / writeBack(id) / mvu() / protocol() / compatMode() / deps(force?) / scan(cards?) / changelog() / recompute(opts?) / varScope() / varHints() / initVar() / stateOf(id,scope?) / opsOf(id) / invalidate() / stats() / trend()`

## 边界

- 卡自带「隐藏状态栏」类脚本时，对应标签进入白名单，**不会被补**（补了反而多出面板）。
- 只补标签、不动正文与数据；所有动作在面板可见；一键关闭即完全还原。
- 自动兜底只在**检测不到 MVU** 时接管（MVU 在场完全不碰，避免二次应用）；模型漏输出变量块时的「静默补一次」会调用 API，默认**关**，需要时在面板第②组打开。
- 本卡有 `.transform()` / `.refine()` 这类静态解析不了的 Zod 约束时，**如实报告**（面板「无法离线校验的约束」计数 + 写变量那一刻弹一次气泡），只应用可静态校验的部分，不假装全做了。
